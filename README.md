# Peak
### What is Peak?
The concept behind Peak is that it is a climbing game up an endless mountain, collecting coins and buying upgrades to slow down the rising lava.
Currently, it's very far from being completed and is very rudimentary. 
### Current Features
- Normalized Movement
- Collecting Coins and Buying Speed Upgrade using a button.
- Rudimentary Menus.
### Future Features
- Adding jumping
- Platforms to jump on or ways to get to higher elevation. 
- Creating Progress Bars and other info indicators.
- Creating endless scrolling.
### How to Play
Currently, there isn't much to do. Really the only things you can do are collect coins, buy speed upgrades by clicking the big black box, and don't die to the lava.
The menus do not currently have functionality either, so pretty much nothing to do.
